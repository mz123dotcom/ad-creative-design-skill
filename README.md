# ad-creative-design-skill
广告创意设计 · 免费 Skill
适配：豆包 Seedance 2.0 Fast

> 本项目是 Skill 而非 Agent。
> 它是一套用于生成商业广告分镜的固定提示规约，**仅输出脚本，不会自动调用视频生成工具**，核心生产力就是提示词本身。
> 只要提示词文本不变，输出格式、风格约束稳定，可加载到任意支持自定义系统提示词的大模型。

✅ 免费开源 | MIT License | 适合产品短视频、电商广告、新品宣发
✅ 自动产出：风格提炼 + 旁白文案 + 带英文提示词的分镜 + 音效设计
✅ 自带两套Demo：半入耳耳机、银白流体屏旗舰手机（脚本 + 配套成片）

## 默认参数
- 默认时长：15s
- 默认画幅：16:9 横屏
- 默认分辨率：720p
- 目标模型：Seedance 2.0 Fast
- 镜头数量：6–8镜高密度剪辑

## 🚀 使用方法
1. 复制 `skill_system_prompt.md` 全部内容，作为系统提示词加载到豆包
2. 上传你的产品图片，发送指令：`生成广告脚本`
3. 拿到分镜脚本，每个分镜单独在豆包【图生视频】生成
4. 剪映拼接、配音、添加音效，完成成片

## 📁 仓库内容
- `skill_system_prompt.md`：Skill核心（主提示词）
- `template.md`：空白模板，手动写脚本时使用
- `demo/`
  - `demo_earbud.md`：小米半入耳耳机完整15s广告脚本
  - `demo_silver_phone.md`：银白流体屏旗舰手机完整15s广告脚本
  - `assets/`：存放参考原图、生成好的Demo成片视频
- `LICENSE`：MIT开源协议

脚本提示词针对 Seedance 2.0 Fast 特性做了轻量化处理，复杂特效容易崩坏，优先推荐干净商业产品摄影风格。
